#Flappy Bird

A simple 2D Flappy Bird-style game made using **Godot Engine 4**.

#Features

- Bird movement with gravity and flap controls
- Moving and randomly positioned pipes
- Continuous pipe spawning
- Pipe and ground collision
- Score system
- Game Over screen
- Restart button

#How to Play

- Press **Space** to flap.
- Avoid the pipes and ground.
- Pass through pipe gaps to increase your score.
- When you crash, click **Restart** to play again.

# Built With

- Godot Engine 4
- GDScript
- 2D Game Development
